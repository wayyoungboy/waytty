# v0.0.2 用户体验分析与优化计划

分析日期：2026-09-23。基线：远程 main 的 `26b53256a0`。本地旧源码逐文件与 `d55e5d40d0` 一致，已备份并同步至最新远程提交。

## 用户流程与发现

| 优先级 | 用户任务 | 当前问题与证据 | 本轮改进与验收标准 |
| --- | --- | --- | --- |
| P0 | 获取正确的新版本 | `main.dart` 禁用了 UpdateProvider；UpdateService 默认访问 YourSSH 仓库，macOS 仅识别 DMG，而 waytty 发布 ZIP。 | 设置中开放手动检查，访问 wayyoungboy/waytty；识别 Universal ZIP，保持 Intel/ARM 匹配；启动和聚焦不产生后台更新请求。 |
| P1 | 弱网下检查、下载并重试 | HTTP 检查没有超时；下载直接覆盖目标文件；无摘要时截断文件可能被当作成功；异步完成可能通知已销毁的界面。 | 检查/下载有超时，下载使用独立目录并校验长度及已有 SHA-256；失败清理临时文件、保留原下载；并发检查去重，销毁后不再通知或启动安装包。 |
| P1 | 快速找到一台连接 | ConnectionCenter 使用整段字符串匹配，首尾空格导致无结果，用户名不可检索，多字段组合词无法命中。 | 忽略首尾和重复空白、大小写；名称、地址、用户名、分组、备注、标签可组合搜索；保留 IPv6 和带冒号的普通搜索。 |
| P1 | 从搜索无结果返回工作 | 空状态始终只显示“添加连接”；搜索框没有清除入口；批量按钮统计所有已选项，实际只连接可见项；英文连接按钮会超出固定操作列。 | 提供清空搜索、重置筛选；首次空列表提供添加和导入；批量按钮数量与实际可连接的可见选中项一致；操作列约束按钮宽度，中文/英文均无溢出。 |
| P2 | 安装与升级 | README、官网、应用版本和发布资产须保持一致；初版用户没有可靠的应用内升级入口。 | 发布 v0.0.2、源码与校验文件，明确初版手动下载步骤；保留 ad-hoc 签名及目标平台实测边界。 |

## 本轮范围

先完善日常查找连接与升级流程，沿用现有界面和中文/英文资源。远程 main 已有账号存储、手动认证和稳定性修复随版本交付；公开包仍使用本地模式，云端服务未配置时不宣称账号备份可用。

后续候选：连接失败的分类型诊断与日志复制、文件传输中断恢复体验、串口设备热插拔、移动端与 Intel 实机验收。它们需要各自的交互设计与目标环境验证，未计入本次交付承诺。

回归覆盖真实用户结果：匹配与无结果恢复、中文/英文空状态、可见选择、正确更新源和安装包、弱网失败与下载完整性、生命周期及并发。执行完整 Flutter 静态分析/测试、翻译检查、官网检查、仓库隐私检查和 macOS Release 构建；测试仅使用夹具与隔离的本机 SSH 服务。
