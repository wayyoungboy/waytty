# 版本升级与数据迁移

waytty 使用独立的应用标识 `io.github.wayyoungboy.waytty`。早期开发包的应用标识、钥匙串服务、笔记键、插件目录和同步接口与当前版本不同。新版本首次启动会使用独立的数据空间，**不会自动找到早期开发包中的连接、密码、笔记或云端快照**。

升级不会删除旧数据，但请先完成导出，再替换旧应用。不要把连接文件、私钥、录制或同步码提交到公开仓库。

## 本地数据

1. 在旧版「连接」中清除搜索和分组过滤，选择「导入与导出 → 导出当前列表（不含密码）」，再在新版导入 JSON。导出的连接保留已有密钥路径，但不包含私钥文件与密码。
2. 笔记在旧版逐篇导出 Markdown，在新版导入；标题、标签和连接关联需检查或重新设置。命令片段、分组配置和偏好请保留副本并在新版重新设置。
3. 在新版重新输入连接密码、私钥口令、AI 密钥和同步配置。旧钥匙串条目不会被自动读取、复制或删除。
4. 旧插件需自行复制到 `~/.waytty/plugins/`；录制与生成的密钥默认保存到 `Documents/waytty/`。旧文件保持原位，可使用文件选择器重新选择；移动私钥后需更新连接中的文件路径。
5. 确认新版本数据完整、连接可用后，再决定是否清理旧应用及其数据。不要在未验证前删除唯一副本。

## 云端账号与旧同步码

当前账号服务使用独立 SQLite / MySQL 后端，旧 Supabase 同步码入口已移除。旧模式启动后回到本地，不会自动连接旧后端，也不会删除本地连接或旧云端快照。需要旧快照时，先用旧版本取回并保留本地副本，再在新版注册邮箱账号，手动创建加密备份。新账号备份不包含笔记、命令片段或私钥文件，迁移范围见 [云端账号说明](CLOUD_ACCOUNT.md)。

终端实时共享原来依赖旧后端，当前版本暂时停用。局域网扫码传输继续可用。仓库中的旧 SQL 和离线加密兼容工具只供历史数据恢复参考，不属于新部署流程。
