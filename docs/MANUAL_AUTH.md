# 手动认证与凭证边界

2026-09-18 起按用户要求禁止自动读取系统钥匙串、私钥文件或 SSH Agent。用户随后明确要求“和链接一起保存”，因此允许将用户主动粘贴并勾选保存的私钥加密保存在 waytty 本地。Flutter 主应用已移除 `flutter_secure_storage` 依赖；不读写、迁移或删除系统中既有凭证。

## 连接方式

- 新建 SSH 传输时，没有已保存私钥则弹出手动认证框；已有私钥则在本地私钥库解锁后复用。密码认证输入密码；私钥认证粘贴完整 PEM/OpenSSH 私钥，可输入解密口令；证书认证还需粘贴公用 SSH 证书。用户自行粘贴，应用不主动读剪贴板。
- 普通连接和“测试连接”统一调用主机指纹校验器，分别校验目标及每级跳板机；首次遇到的指纹弹窗显示服务器地址、端口、密钥类型及 MD5 指纹，用户核对并勾选确认后才保存和认证；已信任且相同的指纹直接通过，变更显示新旧指纹警告。没有可用校验器、用户拒绝或取消时，认证不继续。关闭连接会同时撤销指纹确认，迟到的同意不会写入信任记录。
- 跳板机各自使用其连接记录中的已保存私钥或手动认证；带用户名的代理要求手动输入代理密码。认证取消立即结束，不自动重试或再次弹窗。关闭最后一个会话或断开操作会撤销等待中的认证、代理输入及网络请求；关闭的标签页不会因迟到结果开启 shell。共享跳板机仅在最后一个使用者退出后释放。
- 旧 Agent 类型按手动私钥认证处理；禁用 Agent 认证、Agent 转发和钥匙串/密钥文件回退。启动不再扫描 `~/.ssh`。已存的密钥路径只作元数据展示，不作认证来源。
- SFTP、监控、MCP、端口转发与命令工具仅使用已连接的 SSH 传输；没有连接就提示先手动连接。有效连接内新开通道不需要再次输入；传输断开后须手动发起连接；已解锁的已保存私钥可复用，后台工具和自动重试不能读取凭证或弹出认证框。
- 提权 SFTP 每次需要密码时手动输入，不读取已存 sudo/登录密码，无“记住”选项。

## 保存范围

手动粘贴私钥时可勾选“随此连接保存私钥”（默认勾选），取消勾选则仅用于本次认证。仅已保存的连接允许保存私钥，新建连接的“测试连接”不会遗留凭证。保存包含私钥、可选私钥口令及 SSH 证书，均以 AES-256-GCM 密文保存于独立偏好命名空间 `waytty.local_ssh_keys.v1`，使用 PBKDF2-HMAC-SHA256（600000 轮、随机盐）从用户设置的本地解锁密码派生密钥，按连接 ID 设置独立认证上下文。

首次保存需设置至少 8 个字符的本地解锁密码；密码不落盘、不进入系统钥匙串，与云端保险库密码独立。重启后解锁一次即可使用已保存的私钥，直到手动锁定或退出。连接编辑界面提供保存、替换、删除和锁定入口；忘记解锁密码可删除全部已保存私钥，再重新粘贴和设置密码。删除连接或用导入/恢复替换掉连接时同步删除其私钥，即使私钥库已锁定也可删除。改名不影响使用，修改地址、端口、用户名、协议、认证类型或选择的 key ID 后不会复用旧记录。

私钥不进入 Host JSON、连接导出或云端备份；不扫描、不迁移旧钥匙串或私钥文件。表单关闭清空控制器，解锁后的材料只缓存在本次进程中；锁定清除缓存，但已认证 SSH 连接继续运行。Dart 字符串无法承诺物理内存擦除。

连接编辑器显式输入的密码、代理密码仅留在本次运行的内存；重启后消失。AI API key 也仅留内存，每次启动重新输入；模型和端点等非密钥设置继续保存。S3 工具的配置与凭证只保留在当前页面内存，重新打开需手动填写，不读取旧钥匙串配置。连接、分组、指纹和已有密钥元数据不变。

用户主动执行的密钥生成/文件登记工具仍保留，但其结果不会自动提供给 SSH 认证。云端显式备份的范围和限制见 [CLOUD_ACCOUNT.md](CLOUD_ACCOUNT.md)。旧钥匙串条目及旧偏好中的凭证不读取、不自动迁移、不删除；启动时的旧沙盒数据自动迁移也已关闭。旧 Agent 转发、私钥文件加载及枚举辅助入口保留拒绝桩，不执行传入回调。

## 验证

回归覆盖所有 SSH 认证类型未输入即拒绝、加密私钥解析、手动取消、跳板与代理、后台任务不自动连接、认证对话框、内存凭证重启隔离，以及平台凭证通道零调用。回归还覆盖首次信任中英文窄屏弹窗、取消/排队、已知指纹免重复提示及变更警告。“测试连接”的 10 秒网络超时不计用户核对指纹的等待（弹窗自身 2 分钟未确认则拒绝）。隔离 loopback fixture 用测试密码/私钥验证真实 SSH 与 SFTP；不连接用户已保存的服务器。

本地保存新增回归覆盖密文持久化、重启锁定、错误密码、连接绑定、跨连接密文替换拒绝、锁定时删除、取消解锁、保存选择、替换/删除入口和中英文窄屏布局。
