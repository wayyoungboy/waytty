# 本地离线与云端账号

## 使用方式

首次启动默认「本地离线」，无需注册。连接设置保存在本机应用存储，手动输入的密码只留在本次运行的内存中，不读写系统钥匙串。「离线」指停止云端凭据备份；用户主动连接 SSH、检查更新等网络功能不受影响。

在设置的「连接存储」中选择「云端账号」：

1. 使用邮箱注册；登录密码为 **9–16 个 Unicode 字符**，不裁剪、不静默截断密码。邮箱去除首尾空格并转小写。
2. 输入邮件中的 **6 位验证码**，验证通过后才能进入云端凭据操作。验证码由独立服务端生成和验证； **10 分钟有效、60 秒发送间隔**。客户端支持重发倒计时、错误/过期提示、更换邮箱。已验证账号重复注册返回相同响应；验证码还绑定本次注册的随机令牌与密码。
3. 设置或输入独立的 **保险库密码（9–16 位）**。新建时重复确认。登录密码只用于账号认证；保险库密码不发往服务器。不要把二者设置为相同密码。
4. 点击「保存到云端」加密备份连接设置与连接登录密码；在另一台设备登录、解锁后点击「恢复到此设备」。保存覆盖已有云端快照、恢复替换本地连接前均有确认。

当前是显式保存/恢复的备份模式，没有后台同步或版本历史。保存时，仍在连接列表中的主机会保留本次未重新输入的云端密码；显式输入的新值（包括空字符串）替换旧值，删除连接也会从下一份备份移除其密码。客户端只在用户主动保存、已解锁保险库后合并当前修订的云端密码，不会将其填入本地认证框；云端修订变化则拒绝覆盖。新增密码来自本次运行中用户在连接编辑器输入或显式恢复到内存的值，不会提取旧钥匙串记录；SSH 认证弹窗输入不进入备份。恢复的密码也不自动用于 SSH 建连，仍需手动输入。登录、注册、邮箱验证、解锁本身都不上传或覆盖本地连接。私钥文件、私钥口令、sudo/代理密码、AI 密钥、笔记和设备设置不在这个账号备份中。使用私钥的连接每次新建 SSH 传输时都需手动粘贴完整私钥，不读取已登记的私钥路径。

切回离线或退出登录会停止账号客户端、清除内存中的登录会话和保险库密码，并阻止尚未发出的上传；已经到达服务端的请求无法撤回。本地连接和云端快照都保留。账号会话不写入磁盘；重启应用后需重新登录与解锁。断网不会影响本地连接管理，云端失败可手动重试。

旧同步码云同步入口已移除，已有旧配置会回到本地模式。旧配置、本地连接和远端旧快照不会被删除；需要旧数据时先用旧版本取回，再在新版主动备份。扫码传输继续可用。依赖旧后端的终端实时共享暂时停用，自建实时共享传输尚未实现。

## 加密和数据隔离

- AES-256-GCM，每次保存使用新的 16 字节随机 salt 和 12 字节 nonce；PBKDF2-HMAC-SHA256 使用 600,000 次迭代。版本固定为 `waytty-vault-v1:`，拒绝不识别的格式和超过 16 MiB 的载荷。
- 当前账号 ID 作为认证附加数据，密文不能直接换到另一个账号解密；错误密码与内容篡改都会认证失败。登录密码、保险库密码不持久化在应用偏好中。
- 独立服务端默认用 SQLite，也支持 MySQL。`users` 保存邮箱与 scrypt 密码哈希；`sessions` 保存随机令牌的哈希；`email_challenges` 保存验证码 HMAC。`account_vaults` 只保存用户 ID、密文、修订号和更新时间。API 根据登录会话决定归属，不接受客户端指定的用户 ID。
- 更新必须携带解锁时观察到的修订号；首次创建也检查竞争。冲突拒绝覆盖并要求重新解锁。恢复期间检测本地连接是否变化，变化则中止。
- 忘记保险库密码无法通过重置登录密码恢复云端内容；仍保存在设备上的连接不受影响。账号密码找回、保险库密码修改与恢复密钥暂未提供客户端入口。

## 部署

客户端已接入，但仓库不包含真实云端项目或邮件服务密钥，开发构建默认只开放本地模式。上线需要运营方完成：

服务端独立维护在 [waytty_server](https://github.com/wayyoungboy/waytty_server)，包含独立认证 API、SQLite / MySQL 建表脚本、SMTP 邮件发送和部署说明。服务端、数据库和邮件密钥不进入客户端仓库。

1. 服务端安装 Node.js 22.16+，复制 `.env.example`，生成随机 `VERIFICATION_SECRET`。
2. 默认 `DB_DRIVER=sqlite`，持久化 `SQLITE_PATH` 文件；多实例部署使用 `DB_DRIVER=mysql` 并配置专用数据库账号。首次启动会建表。切换数据库不会自动迁移旧数据。
3. 配置 SMTP、发信域名及 SPF/DKIM。验证码 10 分钟有效、最多失败 5 次、60 秒内不能重发；发送和登录限流保存在数据库，重启仍有效。生产验收需实际测试收件、垃圾箱、重发和过期行为。
4. 启动服务端并通过 HTTPS 反向代理提供 API，客户端构建仅传入公开服务地址：

```sh
WAYTTY_CLOUD_URL=https://your-waytty-server.example \
./script/build_and_run.sh --build
```

Android、Windows 构建脚本接受相同环境变量；也可直接使用 Flutter 的 `--dart-define=WAYTTY_CLOUD_URL=...`。不需要公开 API key，数据库与 SMTP 凭据仅放在服务端。

HTTP 接口为 `/v1/auth/signup`、`verify`、`resend`、`login`、`logout` 和 `/v1/vault`。注册返回内存中的 `registration_token`；验证码校验必须携带该令牌。登录会话有效 24 小时；退出时尝试撤销，无法连接服务端时按期过期。客户端不自动跟随重定向，避免将登录请求发送到其他地址。

## 方案参考与验证

注册使用常见的“邮箱 + 密码 → 邮箱验证码 → 激活账号”流程。可参考 [Clerk 注册选项](https://clerk.com/docs/guides/configure/auth-strategies/sign-up-sign-in-options) 和 [Auth0 邮箱验证](https://auth0.com/docs/manage-users/user-accounts/verify-emails)。本项目自行实现认证与数据库存储，不接入这两个身份服务。注册验证证明邮箱归属，不等同于每次登录的多因素认证。

客户端测试覆盖密码长度、邮箱校验、验证码失败/激活/冷却、加密往返/随机性/篡改/跨账号拒绝、退出期间请求取消、冲突保护、独立 HTTP 协议和离线偏好迁移。服务端对 SQLite 和隔离 MySQL 实例运行相同的 HTTP 与数据库测试，覆盖持久化、并发事务、账号隔离、令牌绑定、验证码限次及会话撤销。**不要对生产数据库执行测试夹具。**

尚未部署真实云端、发送真实邮件或完成原生安装包与跨设备联调。具体部署配置和备份恢复操作见服务端 README。
