# waytty 串口调试

更新：2026-09-13。基础功能已实现；macOS 发布构建与设备枚举界面已检查，尚无真实 USB 串口回环验收。Windows/Android 已接入代码，尚未在对应系统构建或操作硬件。

## 使用

1. 桌面进入「连接 → 串口」。Android 进入连接页右上角的串口图标。
2. 接上适配器后刷新设备列表，选择设备和参数，再点击「连接串口」。列表枚举不会自动打开端口。安卓会请求系统 USB 访问权限。
3. 在独立标签中查看文本或 HEX；底部选择文本/HEX 发送和换行方式。默认不追加换行，无本地回显，避免重复展示设备回显。
4. 可保存有名字的参数配置。配置与 SSH 主机独立保存，不同步系统端口路径或设备访问权限。

默认参数是 115200、8 数据位、无校验、1 停止位、无流控。当前支持 1–4000000 的自定义波特率、5/6/7/8 数据位、无/奇/偶校验、1/2 停止位及无/RTS-CTS/XON-XOFF 流控；具体设备或驱动不支持时会报错。DTR/RTS 初始设为低电平，硬件流控时 RTS 由驱动管理；打开设备本身仍可能改变线路状态。

## 收发与记录

- 原始字节保留，UTF-8 文本从连续的字节缓存解码，HEX 可查看 NUL、非法编码和控制字节。接收视图不会自动向设备发送终端应答。
- 接收文本/HEX 显示最近 64 KiB；收发记录视图显示最近 256 条。后台缓存最多 512 KiB 或 2048 条收发记录，先到者生效。缓存淘汰字节数明确展示，不等于设备线上丢包统计。
- 暂停显示仍继续接收；清空显示保留累计收发计数。导出原始 RX 二进制或含应用时间、方向和 HEX 字节的 JSONL，范围是当前仍保留的缓存。
- 发送历史最多 30 条，保留在当前面板中。定时发送固定启动时的字节，间隔 100–3600000 ms，在上一轮结束后开始计时，避免堆积发送任务。
- 单次手工发送最多 64 KiB；文件最多 16 MiB，以 256 字节块提交。停止会取消尚未提交的部分，已经交给驱动的字节不能撤回。
- 驱动确认的写入数量计入 TX；这不证明设备已经执行命令。写入失败或超时会报告结果未知并关闭会话，不自动重发。
- DTR、RTS 和 200 ms BREAK 均是显式操作；不支持时显示错误。重连需要重新选择/打开，会得到新的会话身份，不重放旧发送队列。

## 平台与生命周期

macOS/Windows 使用 `flutter_libserialport` 0.6.0 + Dart `libserialport` 0.3.0+1；每个端口在独立 isolate 中执行非阻塞读写。原生库参数 `timeout: 0` 代表阻塞等待，因此这里使用默认负值的非阻塞调用。设备列表目前手动刷新，已连接设备的读取失败会释放句柄。

Android 使用应用内 Kotlin `SerialChannel` 和 `usb-serial-for-android` 3.11.0，未采用 `usb_serial` 插件的异步写入队列。独立处理 USB 设备/端口身份、设备授权、取消打开、线程读写及关闭。应用转入后台时关闭串口连接；恢复前台不会自动重连。需要 USB Host/OTG 硬件，尚未验证具体平板和 USB 芯片。

Flutter 收到字节后向原生驱动回传接收确认，限制尚未处理的通道数据；原生与 UI 的读取流程不会无限积压消息。暂停显示不会暂停该接收链路。

许可证文本位于 `crossplatform/app/assets/serial-licenses/`，随应用打包；完整说明见根目录 THIRD_PARTY_NOTICES.md。
