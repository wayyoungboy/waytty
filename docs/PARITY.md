# waytty 功能对照

目标是高保真复刻 XTerminal 的界面与主要工作流，最终覆盖除 RDP 和暂不需要的 VNC 外的功能。Flutter 是主实现，SwiftPM 原型仅保留参考。**下表区分现有实现与尚未验收项，不能将开发版等同于完整复刻完成。**

| 模块 | 当前实现 | 尚待完成或验收 |

| 主界面 | 深色绿色工具式界面、顶部模块、连接中心、协议页与分组树 | 二级页面逐项高保真对照、可调整列宽和列顺序 |
| 连接管理 | SSH/Telnet、增删改查、复制、多级分组、移动/解散分组、收藏/最近/常用、搜索、批量连接、JSON 导入导出 | 更多源格式迁移、原应用全部排序/列配置与操作细节 |

## 验证方法

- Flutter 全量静态分析和测试，包含继承的协议/服务/界面测试及本项目新增回归。
- 本机 asyncssh 隔离服务：真实认证、中文 UTF-8、执行状态与 stderr、命令超时/大输出、中文与特殊字符 SFTP 文件名、二进制续传/重命名/权限/删除。
- 临时 PostgreSQL：匿名表权限禁止、RPC A/B 令牌隔离、非法令牌/明文拒绝、令牌哈希持久化、删除隔离。
- AI 使用内存 HTTP/SSE fixture 验证 OpenAI/Anthropic/Gemini 分片、取消与密钥处理；没有调用付费 API。
- i18n 检查所有资源及插值占位参数，测试默认中文、切换与保存、原始用户文本保留、桌面/平板/窄屏选择器布局。

测试和 GUI 操作只使用本应用及本机隔离目标，不读取原 XTerminal 的保存连接或密码。
