# waytty 功能对照

waytty 围绕连接管理、终端、文件传输、监控和串口调试提供统一工作区。Flutter 是主实现，SwiftPM 原型仅保留参考。RDP 不在范围内，VNC 暂不启用。**下表区分现有实现与尚未验收项。**

| 模块 | 当前实现 | 尚待完成或验收 |
|---|---|---|
| 主界面 | 深色绿色工具式界面、顶部模块、连接中心、协议页与分组树 | 二级页面交互验收、可调整列宽和列顺序 |
| 连接管理 | SSH/Telnet、增删改查、复制、多级分组、移动/解散分组、收藏/最近/常用、搜索、批量连接、JSON 导入导出 | 更多源格式迁移、排序与列配置 |
| 终端 | 真 PTY/SSH/Telnet、标签、**递归分屏窗格**（左右/上下、可嵌套、拖拽分隔条、焦点边框、关闭窗格）、广播、搜索、快捷键、录制、会话模板 | 独立终端窗口、全部编码/X11 选项、跨平台输入法与快捷键验收；分屏树的工作区持久化 |
| 串口调试（新增需求） | 串口入口与独立标签、设备枚举/刷新、参数与配置保存、文本/HEX 收发、有界记录与导出、定时/文件发送、DTR/RTS/BREAK；桌面 FFI 和 Android USB Host 通道 | 真实 USB 回环/芯片兼容性、Windows/Android 目标构建、自动刷新设备列表、ANSI 视图、更多编码与串口 AI 联动；见[串口验收](SERIAL.md) |
| SSH 网络 | 手动密码/私钥/证书认证、主机指纹、代理、跳板链、端口转发/心跳；禁用 Agent 与自动凭证读取，断开后手动重连，支持复用已解锁的本地私钥 | 全部服务器和网络组合的端到端验收 |
| 文件传输 | SFTP、本地/远程面板、终端左侧文件树、队列、目录操作、编辑、权限、恢复传输 | 文件预览与批量操作、极端断网和大目录、Windows/Android 文件授权 |
| 主机监控 | 终端工具栏与平板菜单入口、跟随会话的侧栏、Linux CPU 总体/全部逻辑核心/指定核心及趋势、内存/磁盘/负载/交换内存、各网卡速率、暂停/刷新/断线处理；见[使用说明](MONITORING.md) | 其他远端系统、长期历史、阈值告警、多主机总览及 Linux 真机对照验收 |
| 工具 | 命令库、监控、脚本与开发运维/网络工具插件 | 各工具的布局与真实目标验收、非 macOS FFI |
| 笔记 | Markdown 编辑/预览、搜索、导入导出、连接/分组关联、自动保存 | 完整笔记交互验收 |
| 多语言 | 默认简体中文、English、持久化选择；桌面/平板/插件共用资源、macOS 菜单联动 | 动态错误文字持续整理、其他语言、所有长文本页面视觉验收 |
| 凭证与数据 | 密码只留内存、手动粘贴的私钥可随连接本地加密保存并手动解锁；不访问系统钥匙串、不自动读取私钥文件；详见[手动认证](MANUAL_AUTH.md) | 用户现存旧凭据的手动管理；不自动迁移或删除 |
| 云同步 | 本地离线/邮箱账号切换、验证码注册、独立保险库加密、连接凭据手动备份恢复、SQLite / MySQL 后端、会话隔离与修订号冲突保护；保留扫码传输 | 云端与 SMTP 部署后多端实测、自建实时共享、自动合并、版本历史、密码找回与私钥备份 |

| MCP | 本机 HTTP、令牌、按主机/目录授权、命令超时/输出限制 | 所有第三方 MCP 客户端联调；不是后台无限制执行服务 |
| 发布 | macOS 构建/签名脚本、waytty 应用和 zip、许可文件 | Windows/Android 实机包与验收、Developer ID 签名/公证 |

## 验证方法

- Flutter 全量静态分析和测试，包含继承的协议/服务/界面测试及本项目新增回归。
- 本机 asyncssh 隔离服务：真实认证、中文 UTF-8、执行状态与 stderr、命令超时/大输出、中文与特殊字符 SFTP 文件名、二进制续传/重命名/权限/删除。
- 临时 PostgreSQL：匿名表权限禁止、RPC A/B 令牌隔离、非法令牌/明文拒绝、令牌哈希持久化、删除隔离。
- AI 使用内存 HTTP/SSE fixture 验证 OpenAI/Anthropic/Gemini 分片、取消与密钥处理；没有调用付费 API。
- i18n 检查所有资源及插值占位参数，测试默认中文、切换与保存、原始用户文本保留、桌面/平板/窄屏选择器布局。

测试和 GUI 操作使用演示数据及本机隔离目标，不连接用户保存的服务器。

终端左侧文件工作区的操作与边界见 [FILE_WORKSPACE.md](FILE_WORKSPACE.md)。
