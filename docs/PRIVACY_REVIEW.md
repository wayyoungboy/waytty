# 开源前隐私检查

检查日期：2026-09-15。范围为待发布源码（包含未跟踪文件）、本地全部 26 个提交及 241 个历史文件对象、文档截图，以及最新本地 macOS 开发包。报告不记录实际个人邮箱、主机地址或密钥内容。

## 发现与处理

- 历史提交的作者与提交者使用个人邮箱。发布准备目录使用独立的首次提交及 GitHub noreply 邮箱，不继承这些历史；原开发仓库历史保留。不要直接推送原开发仓库的全部历史。
- 上游截图测试包含固定的开发者主目录、设备名及用户名，已改为可配置截图目录和演示数据；文件系统测试使用通用示例用户。
- 源码目录中的预编译 QuickJS 动态库及现有 macOS 开发包包含编译机器的绝对路径。预编译库、构建目录和旧安装包排除在源码发布之外；QuickJS 由现有构建脚本从源码编译。现有开发包不能直接作为已通过隐私检查的公开 Release 上传。
- 自动扫描命中的 SSH 私钥均为公开上游测试夹具，与固定上游提交逐字节一致；测试依赖这些夹具，因此保留并按内容校验放行。它们不能作为真实主机凭证使用。
- 其他命中为测试用同步码和翻译资源中的消息标识；放行精确内容，新增或修改内容仍须重新检查。
- 文档应用截图仅包含空连接列表、设置、通用串口入口或测试生成的监控数据。用户反馈中包含真实 SSH 输出的截图未进入源码目录。
- `.gitignore` 增加环境文件、凭证、录制、数据库、日志及本地工具配置的排除规则。已经跟踪的文件仍需扫描，不能仅依赖忽略规则。

## 每次发布前

安装 [Gitleaks](https://github.com/gitleaks/gitleaks)，执行：

```sh
python3 script/check_privacy.py
python3 script/check_privacy.py --history
```

也可通过 `WAYTTY_GITLEAKS` 指定可执行文件。脚本复制 Git 已跟踪文件与未忽略的候选文件到临时目录，再扫描；检查结果只输出规则、路径与行号，扫描报告脱敏且随临时目录删除。已审核测试数据的例外保存在 `privacy-allowlist.json`，绑定具体内容的 SHA-256，不豁免整个测试目录。

首次发布另需检查提交身份：

```sh
git log --all --format='%h %an <%ae> / %cn <%ce>'
```

网站构建只复制明确列出的静态资源和审核过的文档截图，GitHub Pages 仅上传 `dist/site`，不上传整个仓库或应用安装包。官网不加载外部字体、统计脚本或第三方图片，不要求输入服务器或 API 凭证。

这是针对本次文件快照的检查，不代表未来提交或重新构建的安装包自动通过。公开应用二进制前，应在无个人路径的隔离构建环境重建，并再次检查二进制字符串、签名身份、压缩包清单及截图。
