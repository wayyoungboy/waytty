# 主机监控

连接 SSH 后，点击终端上方工具栏中的「监控」，在右侧查看当前主机。切换会话时面板跟随切换；本地终端、Telnet、串口和共享观看会话不会启动 SSH 主机采集。平板端可在终端的更多菜单中打开「监控」，主机列表原有的监控入口也继续可用。

- CPU、内存使用情况及最多 60 次采样的趋势；1/5/15 分钟负载、运行时间、交换内存、磁盘使用量。
- CPU 右侧下拉框可选「总体」「全部核心」或「核心 N」。总体显示整机使用率；全部核心显示总体和可滚动的各核心卡片；指定核心显示该核心使用率和趋势。编号对应 Linux 的逻辑 CPU ID（例如 `cpu0`），不是物理插槽编号。
- 每次采样同时读取总体与所有逻辑核心，切换视图无需额外请求。新上线、计数重置或尚无有效差值的核心显示「等待有效采样」，趋势在缺失样本处断开；所选核心下线时回到总体。视图选择在面板当前会话内保留，关闭或切换会话后默认显示总体。
- 各网卡分别显示接收和发送速率。首个样本或网卡计数重置后等待下一次采样，虚拟网卡不与物理网卡叠加为总流量。
- 系统信息每 5 秒采集，防火墙信息每 30 秒采集。可手动刷新、暂停、继续或关闭侧栏。设置中的网络速率小浮层仍可独立开启。
- 断线后停止定时采集；恢复连接后重新开始。切换主机、暂停或关闭后，旧请求的迟到结果不会更新界面。采集失败时显示错误，保留的上一条数据带更新时间，不再标记为「实时」。

当前系统指标针对可读取 `/proc` 的 Linux SSH 主机；其他远端系统会显示中文的不可用提示，不以零值冒充成功。端口最多采集前 200 行，进程名称和防火墙详情取决于远端工具与账户权限；防火墙内容沿用现有检测器，不等于完整安全审计。趋势是当前面板内的临时记录，尚无后台历史存储、阈值告警或多主机总览。

采集复用已经认证的 SSH 连接，通过独立 exec 通道执行固定只读命令，不向交互式终端注入命令，不安装 agent，也不自动重连或请求提权。单个采集请求限制为 8 秒和 512 KiB；同一采集器不会重叠请求。关闭时停止后续轮询，已发出的请求最多运行到超时，迟到结果被丢弃。

统计字段参考 [Linux `/proc` 官方文档](https://docs.kernel.org/filesystems/proc.html)。CPU 汇总排除已包含在 user/nice 中的 guest/guest_nice 重复计数；网卡速率用远端 uptime 差值计算，避免本机时钟跳变。
