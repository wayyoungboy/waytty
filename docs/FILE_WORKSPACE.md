# 终端文件工作区

桌面终端默认显示左侧文件工作区。工具栏的文件树图标和面板右上角关闭按钮控制显示；拖动面板右边界调节宽度。文件面板与右侧监控、终端设置或命令片段可以同时显示。窄窗口保留最小面板宽度，必要时横向滚动工作区。

- SSH：自动关联当前已连接的会话，复用现有 SFTP 服务、主机校验、认证和 sudo SFTP 配置。不为断开或只读共享会话建立文件连接。
- 本地终端：浏览本机文件，复用本地文件操作。
- 单击目录或箭头展开/折叠，按需加载子目录；单击文件选中，双击文件打开，双击目录进入该目录。右键菜单复用现有编辑、重命名、删除、权限和复制路径操作。
- 路径栏支持直接输入路径、前进/后退和刷新。SSH 的定位按钮在 shell 提供当前目录时可用，点击后跳转；终端中执行 `cd` 不强行打断手动浏览。
- 每个会话分别保留浏览路径、展开/选择和滚动状态。切换终端标签、导航到连接中心/设置等页面、隐藏后重开面板均保留已加载数据和在途目录请求，不因切换重复列目录；需要更新时点击刷新。断开、关闭会话或重启应用后重新加载，文件树不持久化到磁盘。
- 监控按会话保留快照、历史、CPU 视图和手动暂停状态。隐藏或切到其他标签时暂停轮询，返回时先显示缓存，再按正常周期更新；断开或关闭后停止采集并清理状态。
- 名称过滤仅作用于已加载文件，保留目录供继续浏览，不递归扫描整台服务器。刷新会重新加载根目录并折叠旧子树。
- 大文件、二进制文件和远程编辑沿用现有 SFTP 编辑器规则；传输队列继续使用独立 SFTP 页面。

## 验证

新增文件树、会话隔离、异步失效、目录定位、面板状态与宽度、嵌套文件选择及窄面板测试。运行 `./script/check_crossplatform.sh` 检查本地化、静态分析与 Flutter 测试。真实 SSH fixture 需设置 `WAYTTY_SSH_FIXTURE_PYTHON`；不使用已保存的用户服务器自动验收。
