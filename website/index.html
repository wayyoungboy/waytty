把日常操作，
放在同一个工作区。

整理会话，在终端旁传输文件。发现机器变慢时，直接展开 CPU 明细，查看每个核心的负载。

⌘

连接再多，也有条理。

用分组、收藏、最近访问和搜索整理主机。标签、分屏与广播输入，适应多会话工作。

总体之外，
看见每一个核心。

在总体、全部逻辑核心和单个核心之间切换。结合使用率趋势、内存、磁盘和各网卡速率，了解 Linux 主机当前状态。

从服务器，
到桌上的开发板。

选择端口并保存参数，支持文本与 HEX 收发、记录导出，以及 DTR、RTS、BREAK 控制。真实硬件兼容性仍在持续验收。

应用实图 · 串口连接入口
↗

文件就在终端旁

SFTP 与本地文件面板、传输队列、远程编辑和权限管理，减少来回切换。

>_

把常用操作留下来

复用命令片段、记录 Markdown 笔记、录制终端会话，也可以配置自己的快捷键。

◈

连接与凭证由你配置

支持 SSH 密钥、Agent、跳板链与代理。云同步按需配置，应用可在本地使用。
