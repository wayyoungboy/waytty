    进入「连接 → SSH → 新建连接」，填写主机信息。首次连接请核对服务器指纹。

还有几个问题。

需要注册才能使用吗？

不需要。本地连接管理与终端工具无需账号。离线模式可以管理本机资料；连接远程主机和传输文件仍需网络。邮箱账号备份为可选功能，尚未包含在 v0.0.1 中。

云端会保存明文凭据吗？

邮箱账号备份在客户端加密连接设置与连接密码，自建服务端使用 SQLite 或 MySQL 保存密文。登录密码与保险库密码各有用途；保险库密码不会发送到服务器，遗失后无法通过重置登录密码恢复备份。私钥文件不在备份范围内。

v0.0.1 支持哪些平台？

v0.0.1 提供 macOS Universal 安装包，支持 Apple Silicon 与 Intel。Windows 和 Android 安装包暂未提供；平台验收、升级说明与问题反馈可查看项目文档。
